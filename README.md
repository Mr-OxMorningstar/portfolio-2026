# Ntwanano A Hlungwane — portfolio

My personal portfolio site. Each version lives on its own branch:

| Branch | What it is |
|---|---|
| `versionX1` | Plain, document-style version: React, TypeScript, Tailwind CSS, and a small Three.js scene from The Office |
| `versionS` | Coming next: a more colourful, interactive version |

## Run it

```sh
npm install
npm run dev      # local dev server
npm run build    # type-check and production build into dist/
```

All page content lives in `src/data/profile.ts`.
